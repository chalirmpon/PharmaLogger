# PharmaLogger Dashboard — หน้าเปิดระบบจาก GitHub Pages

เปิดแดชบอร์ดมอนิเตอร์อุณหภูมิ / ความชื้นของหน่วยงานจากลิงก์นี้ แทนลิงก์ script.google.com

- ไม่มีแถบ "แอปพลิเคชันนี้สร้างโดยผู้ใช้ Google Apps Script"
- ติดตั้งเป็นแอปบนมือถือและคอมพิวเตอร์ได้ (เปิดเต็มจอ ไม่มีแถบที่อยู่)

**วิธีใช้:** เปิด `https://chalirmpon.github.io/PharmaLogger/?api=` ตามด้วยลิงก์ Web app (`…/exec`) ของหน่วยงาน
ครั้งต่อไปเปิด `https://chalirmpon.github.io/PharmaLogger/` ได้เลย เครื่องจะจำลิงก์ไว้ (หน้าตั้งค่า: เติม `?admin=1`)

**ต้องมีในโปรเจกต์ Apps Script ของหน่วยงาน:** ไฟล์สคริปต์ `WebGitHub.gs` (อยู่ถัดจากไฟล์ Code) แล้ว Deploy › Manage deployments › แก้ไข › New version
และ Web app ตั้ง "ผู้มีสิทธิ์เข้าถึง: ทุกคน"

หน้านี้ไม่มีข้อมูลอุณหภูมิ ผู้ใช้ หรือลิงก์ของหน่วยงานใด — หน้าแดชบอร์ดโหลดสดจากระบบของแต่ละหน่วยงาน ออกรุ่นใหม่ไม่ต้องแก้ไฟล์ในนี้
ESP32 ยังส่งค่าเข้าลิงก์ /exec เดิม และ Telegram webhook ทำงานเหมือนเดิม

**ติดตั้งเป็นแอป:** Android — Chrome › ⋮ › ติดตั้งแอป • iPhone — Safari › แชร์ › เพิ่มไปยังหน้าจอโฮม • คอมพิวเตอร์ — Chrome / Edge › ไอคอนติดตั้งในแถบที่อยู่
